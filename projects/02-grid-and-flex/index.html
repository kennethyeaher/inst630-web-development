About this project

Design Notes is an INST630 Homework 2 project by Kenneth Yeaher, based on the component-compex card in the course Figma demos. The same nested card structure appears three times, with original notes about the page and sample discussion prompts.

CSS Grid places the page regions, and Flexbox arranges each card's contents. Cards share a row above 64rem and stack at 64rem and below. Browse the HTML, CSS, and README for the implementation and browser-check instructions.

Explore the layout

Space around the content. Each card has a border and inner padding. The heading uses a bottom margin, while Flexbox gaps set the distance between cards. These schematics show the groups; the full nesting is documented in the README.

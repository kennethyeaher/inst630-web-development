## GitPages

The original project READMEs link to hosted GitHub Pages demos. Those links provide inspectable publishing evidence for the individual projects; the original GitPages assignment submission itself was not supplied. This collection also includes a [local project index](../index.html). Hosting this collection through Pages is a separate configuration, and no collection-level Pages deployment is claimed.

For a publishing review, check that the repository entry point matches the deployment folder, asset paths stay inside that folder, and JSON is served over HTTP. Verify the actual hosted page after deployment rather than treating a successful push as proof of a working page. The collection's [source register](source-register.md) records which source revisions were assembled.

## How to review the collection

- **For a portfolio review:** start with the three [case studies](case-studies.md), open a live demo, and inspect the linked implementation or test.
- **For a course review:** use the table above to trace each component to an implementation or a clearly labeled study companion.
- **For midterm preparation:** answer the [practice prompts](midterm-guide.md), then use the [reading companion](reading-companion.md) to connect code behavior to an interface principle.

The course list supplies topics and deadlines. It does not supply the exact reading excerpts, discussion prompts, grading rubric, or submitted responses. The companions below are organized around those topic labels and the available textbooks. They should not be presented as the original course submissions.
